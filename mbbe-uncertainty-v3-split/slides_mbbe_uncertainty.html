Background & Motivation

Why does parameter uncertainty matter in MBBE?

Model-Based Bioequivalence (MBBE)

  • Traditional BE relies on clinical trials with real subjects
  • MBBE uses PK model simulations to generate virtual BE trials
  • Enables power analysis, sample size planning, and risk assessment
Core Question: When we simulate virtual trials, should we use fixed parameter estimates or propagate the uncertainty from the fitting step?

The Uncertainty Problem

PK parameters (CL, V, Ka, Ω, σ) are estimated from data — they have uncertainty.

Ignoring this uncertainty may lead to:

  • Overconfident power estimates
  • Underestimated type I error
  • Or… it might not matter much?

Uncertainty Methods

Four approaches to handling parameter uncertainty

The Four Methods

1. Fixed (Plug-in)

Uses the point estimate θ̂ from FOCE for every simulated trial. No uncertainty propagated. This is the traditional approach and serves as our reference baseline.

100 identical copies of θ̂

2. VCOV (Asymptotic Normal)

Samples parameters from a multivariate normal distribution on the log scale, using the variance-covariance matrix from FOCE. Assumes asymptotic normality of the estimator.

200 samples from MVN(μ, V)

3. Bootstrap

Resamples subjects with replacement (100 bootstrap replicates), re-fits the model each time, then samples from the bootstrap VCOV. Non-parametric uncertainty.

100 bootstraps → 200 samples

4. SIR (Sampling Importance Resampling)

Draws 200 proposal samples, computes importance weights from the likelihood, then resamples 100 with weights. Samples from the SIR-based VCOV.

200 proposals → 100 resamples

How Uncertainty Is Propagated

Parameter Sampling (Log Scale)

μ = [log(tvCL), log(tvV), log(tvKa), log(tvbio),
       log(ω1²), log(ω2²), log(ω3²), log(σ)]

θdraw ~ MVN(μ, Vmethod)

Parameters back-transformed via exp()
The VCOV matrix V differs by method:
• VCOV: directly from FOCE Hessian
• Bootstrap: from bootstrap replicates
• SIR: from importance-weighted resamples

Per-Trial Simulation Flow

Step 1 Draw θ from parameter pool
Step 2 Set tvbio = T/R ratio of interest
Step 3 Simulate nT + nR subjects
Step 4 Run NCA → AUCinf, Cmax
Step 5 TOST on log-scale data
Result Pass = AUC and Cmax both within 80–125%

Statistical Testing

TOST for parallel-design BE

TOST for Parallel-Design BE

Two One-Sided Tests (TOST)

H0: μT − μR ≤ log(0.80) or ≥ log(1.25)
H1: log(0.80) < μT − μR < log(1.25)

GMR = exp(Δ),   Δ = x̄T − x̄R
90% CI = exp(Δ ± tα, df · SE)
BE Pass: 90% CI for GMR entirely within [0.80, 1.25] for both AUC and Cmax

Parallel Design Specifics

  • Pooled variance: sp² from two independent groups
  • SE = √(sp² · (1/nR + 1/nT))
  • df = nR + nT − 2
  • α = 0.05 (one-sided), giving 90% CI

Operating Characteristics

  • Power: Pass rate when T/R is within BE limits (0.9, 1.0, 1.1)
  • Type I Error: Pass rate when T/R is outside BE limits (0.7, 1.3)

Why Does Type I Error Increase with n?

The Paradox Explained

Larger samples give the TOST more statistical power to detect any GMR near 1.0. When parameter uncertainty shifts θ toward T/R ≈ 1.0, larger n makes it easier to falsely pass the shifted (but biased) trial.

  • With Fixed: θ = 0.7 always → TOST correctly rejects
  • With uncertainty: some draws shift θ toward 1.0
  • Larger n → tighter CI → more of these shifted trials pass

Mechanism

1. True T/R = 0.7 (bioinequivalent)

2. Parameter draw shifts tvbio toward 1.0

3. Virtual trial now has effective T/R ≈ 0.85–1.0

4. With large n, TOST passes this "shifted" trial

5. Result: false positive (type I error)

This is inherent to how MBBE propagates uncertainty — it conflates parameter uncertainty with the T/R ratio being tested.

Key Findings & Conclusions

Key Finding 1: Power Reduction

Propagating parameter uncertainty reduces estimated power by 10–16 pp at moderate sample sizes

At n = 30 per arm and T/R = 1.0, the Fixed method estimates 76% power while uncertainty methods estimate 60–63%. This is a clinically meaningful difference for sample size planning.

Practical Impact

Using Fixed estimates:
  • n = 30 seems adequate (76% power)
  • May lead to underpowered studies
Using uncertainty estimates:
  • n = 30 gives only 60% power
  • Need n ≈ 40–50 for 80% power

Key Finding 2: Type I Error Inflation

All uncertainty methods inflate type I error far beyond the nominal 5% level

At T/R = 0.7 and T/R = 1.3, uncertainty methods produce 10–22% false positive rates. This inflation worsens with larger sample sizes — a counterintuitive and critical finding.

Implications

  • Regulatory concern: If MBBE with uncertainty propagation is used to support a BE filing, the apparent type I error protection may be illusory
  • The uncertainty "leak": Parameter uncertainty shifts the effective T/R ratio, mixing the testing question ("is this T/R bioequivalent?") with estimation uncertainty
  • Not a method-specific problem: All three uncertainty approaches (VCOV, Bootstrap, SIR) show the same pattern

Key Finding 3: Method Choice Matters Less Than Expected

The choice among VCOV, Bootstrap, and SIR has limited impact (≤3 pp difference)

The dominant driver is whether you propagate uncertainty, not which method you use. All three produce qualitatively similar results.

Conclusions

  1. Parameter uncertainty substantially affects MBBE operating characteristics.
    Ignoring uncertainty (Fixed) overestimates power by 10–16 pp and underestimates type I error by 10–21 pp at typical sample sizes.
  2. Type I error inflation is the critical concern.
    All uncertainty methods produce 2–4× the nominal α, and this worsens with increasing n. This calls for adjusted acceptance criteria or alternative testing frameworks.
  3. Bootstrap is the best-performing uncertainty method (marginally).
    Slightly higher power and lower type I error than VCOV/SIR, with the fewest distributional assumptions.
  4. The gap narrows at large sample sizes.
    At n ≥ 60 per arm, power differences become small (<6 pp), though type I error inflation persists.
  5. Sample size planning should account for parameter uncertainty.
    Relying on Fixed estimates may lead to underpowered BE studies.

Recommendations

For Power Assessment

  • Use uncertainty-propagated power estimates for sample size planning
  • Bootstrap preferred for fewest assumptions
  • Add 30–50% more subjects than Fixed-based calculations suggest

For Type I Error Control

  • Current MBBE uncertainty propagation does not maintain nominal α
  • Consider adjusting BE limits or using a separate framework for type I error assessment
  • Fixed plug-in may be more appropriate for regulatory type I error evaluation
Open question: Can the type I error inflation be corrected while retaining the benefits of uncertainty propagation? Possible approaches include calibrated acceptance criteria, penalized uncertainty, or hybrid methods.
